- やったこと（変更したファイル・設定・処理、または設計した取得方法）：`app/retrieval.py`でベクトル検索ヒットの前後1ページを追加取得する処理を実装した。ページ番号だけでなく`document_id`と`section`も一致する場合に限って隣接ページとし、資料・章をまたがないようにした。検索ヒットを優先してページIDで重複を除き、`source`で検索ヒットと追加ページを区別する。Graph検索は従来どおり検索ヒットのみを入口にする。CLIは通常実行で前後ページを含め、`--hits-only`で従来の検索ヒットのみを表示できるようにした。境界・重複排除と検索結果をテストした。
- 比較した質問と、固定した条件（モデル・対象資料など）：演習と同じ「第2回の説明では、LoRAは何を固定し何を学習しますか？ QLoRAは何を加えますか？」。対象は第2回資料（`lec02-main`）、既存の検索索引、`RAG_TOP_K=5`。モデルを使う比較では`gemini-3.5-flash-lite`を固定する。検索結果は`uv run python -m app.retrieval "質問"`と`uv run python -m app.retrieval --hits-only "質問"`で比較できる。
